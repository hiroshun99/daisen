# 題箋

乱立する情報を、コピペして残すノート。

タブもブックマークも、AIの出力も増え続ける。題箋は本文を貼ると題と要約を付け、Markdown / CSV / PDF として書き出せる。書き出したファイルは、別の業務AIのナレッジになる。

## なぜ作ったか

後で読むは溜まるだけで、翌週の自分は中身を思い出せない。保存の単位を URL ではなく本文にし、題箋（タイトル）を機械に任せる。

## できること

- メールアドレスとパスワードで登録・ログイン（ユーザーごとにノートを隔離）
- 本文を貼る → 題と要約の提案 → 確定して保存
- 1件ごとの Markdown / CSV / PDF
- 全件を1つの Markdown にまとめて書き出し（他のAIへ渡す用）
- 空のときはデモ用ノート3件を入れられる

## 技術

React 19 / TanStack Start / Postgres（プレビューは PGLite） / Better Auth / pdf-lib

## 設計で決めたこと

- 本文はユーザーのもの。提案は保存前の補助で、既存タイトルは上書きしない
- AI は保存操作のときだけ呼ぶ。キーが無い環境では人手で題を付けて保存できる
- PDF は日本語フォントを埋め込む。Markdown はチャットに貼れる形
- 認証付きの読み書きはすべてサーバ側の `user_id` で絞る

## 動かし方

```bash
npm install
npm run dev
```

本番で使う環境変数（プラットフォームが注入）:

- `DATABASE_URL` — Postgres
- Better Auth 設定
- `XAI_API_KEY` — 題・要約の提案（任意）

## これから

提案回数の上限、一括 PDF、共有は需要が見えてから。
